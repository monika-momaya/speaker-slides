# Soft Slides

Streamlit app for generating PPTX speaker/session decks from a tagged PowerPoint template.

## Expected template tags
Use tags like these directly inside textboxes on slide 1 of your PPTX template:
- <<SESSION_NAME>>
- <<HALL_NAME>>
- <<DATE>>
- <<MAIN_SESSION_DETAILS>>
- <<SPEAKER_SESSION_DETAILS>>
- <<PLACEHOLDER_1>>
- <<PLACEHOLDER_2>>
- <<SPEAKER_NAME_1>>
- <<SPEAKER_TITLE_1>>
- <<SPEAKER_COMPANY_1>>
- <<SPEAKER_PHOTO_1>>

## Run locally
streamlit run app.py
